# FAVORITE 9 — JYP男性アーティスト 好き顔9選

JYP Entertainmentから発足・デビューした男性アイドル／バンドを対象としたファンメイドの顔ソートです。退社済みアーティストを含み、グループ脱退者・中国支社所属アーティストは対象外としています。JYP Entertainmentおよび各アーティストとは関係のない非公式サイトです。

現在48人を登録しています。

## 使い方
1. `data.js` を編集するとメンバー情報を変更できます。
2. 写真は `images` フォルダに入れます。
3. `index.html` をブラウザで開けば動きます。

## モード
- STANDARD SORT：比較回数を多めにして順位を決定
- QUICK SORT：比較回数を抑えて短時間でTOP 9を決定

## 選択肢
- LIKE：選んだ側を高く評価
- BOTH：両方を高く評価
- SKIP：スコアを変更せず次へ
- BACK：直前の比較を取り消す

## 公開
静的ホスティングにこのフォルダをアップロードすればURLで共有できます。
